# Database.
#
# PyMySQL rather than mysqlclient: it is pure Python, so the Railway builder
# needs no libmysqlclient/pkg-config system packages. backend/__init__.py
# registers it as MySQLdb. Swap in psycopg2-binary if this ever moves to
# Postgres -- settings.py already handles either through DATABASE_URL.

# MySQL 8 authenticates with caching_sha2_password, and PyMySQL delegates that
# handshake to cryptography. Without it the connection dies at login with
# "'cryptography' package is required for sha256_password or
# caching_sha2_password auth methods".
